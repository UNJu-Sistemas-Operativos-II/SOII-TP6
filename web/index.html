Ordene secuencialmente las 6 etapas canónicas de una llamada a procedimiento remoto (RPC). Arrastre las tarjetas desde el banco de origen hacia las posiciones numeradas.

📦 Banco de Etapas Disponibles
🧑‍💻 El procedimiento cliente efectúa una llamada al Stub del Cliente local
📦 El Stub del Cliente empaqueta parámetros y genera una trampa (trap) al núcleo
🌐 El núcleo local transmite el mensaje por la red hacia el núcleo del host remoto
📥 El núcleo remoto recibe el paquete y se lo entrega al Stub del Servidor
⚙️ El Stub del Servidor desempaca los parámetros e invoca al procedimiento servidor
📤 El servidor procesa el requerimiento y retorna el resultado al Stub para el viaje de vuelta
